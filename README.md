# Control Old 2026 Archive

2026 赛季“武林探秘”控制代码归档仓库。

> 当前仓库在上传、整理和安全审查完成前应保持私有。公开不代表已完成许可证或安全审查。

## 归档要求

每个机器人或模块应记录：

- 硬件平台、控制器及关键外设
- 操作系统、工具链、ROS/依赖版本
- 编译、烧录、启动和标定方法
- 对应的最终比赛版本或 Git 标签
- 已知问题、现场注意事项和维护状态

## 建议目录

```text
robots/        按机器人或兵种归档
shared/        经确认可复用的公共模块
docs/          系统架构、接线、标定和操作说明
tools/         构建、部署和诊断工具
```

实际上传代码后，请按真实目录结构更新本节。

## 公开前检查

- [ ] 已扫描当前文件和完整 Git 历史中的密钥、密码与个人信息
- [ ] 已确认第三方 SDK、库、模型和比赛资料允许再分发
- [ ] 已确定并添加合适的 `LICENSE`
- [ ] 已移除构建产物、大型日志和无用二进制文件
- [ ] 关键版本已创建标签并经过负责人复核
- [ ] 仓库公开后设置为只读 Archive，或明确后续维护方式

发现敏感信息时，不要只删除当前文件；应立即轮换相关凭据并清理 Git 历史。
