# Control Old 2026 Archive

2026 赛季 ROBOCON 控制代码归档仓库，包含 R1、R2 两台机器人的上层与下层代码。

> 当前仓库在上传、整理和安全审查完成前应保持私有。公开不代表已完成许可证或安全审查。

## 赛季协作结构

- R1：一名上层电控 + 一名下层电控
- R2：一名上层电控 + 一名下层电控

归档时不能只保存各自代码，还应保留上下层接口、通信协议、标定参数、联调记录以及 R1/R2 协同逻辑，确保以后能够复现完整比赛系统。

## 建议目录

```text
R1/
  upper/       R1 上层代码
  lower/       R1 下层代码
  docs/        R1 接口、标定与联调记录
R2/
  upper/       R2 上层代码
  lower/       R2 下层代码
  docs/        R2 接口、标定与联调记录
shared/        两台机器人共用且已确认可复用的模块
system/        R1/R2 协同、场地流程与全局说明
tools/         构建、部署和诊断工具
```

实际上传代码后，请按真实目录结构调整，不要为了匹配示例而破坏原项目。

## 每部分需要记录

- 负责人及职责范围
- 硬件平台、控制器和关键外设
- 操作系统、工具链、ROS/依赖版本
- 上下层通信接口、单位、坐标系、频率和超时策略
- 编译、烧录、启动、标定与联合调试方法
- 对应的最终比赛版本或 Git 标签
- 已知问题、现场注意事项和维护状态
